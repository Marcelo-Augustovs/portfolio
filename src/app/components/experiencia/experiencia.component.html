  • MaNotes ( My Auxiliar Notes)

    Um sotware para gerenciamento de anotações, controle financeiro e agendamento de eventos com notificações.

    Frontend: JavaFX. Destaques: API REST local, integração segura com JWT, armazenamento offline e interface intuitiva.
